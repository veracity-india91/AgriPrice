AgriPrice 🌾

AgriPrice is a web-based agricultural market price search system developed using Java and Spring Boot.

📌 Project Overview

AgriPrice helps users search and view agricultural commodity market prices such as Onion and other commodities using market price data from a government API.

🚀 Features

- Search agricultural commodity prices
- View state, district and market details
- Display minimum and maximum prices
- REST API integration
- JSON data handling
- Postman API testing
- Spring Boot backend
- MySQL database integration

🛠️ Technologies Used

- Java
- Spring Boot
- REST API
- MySQL
- Hibernate / JPA
- Maven
- Postman
- Git & GitHub

🔗 API Integration

The project uses the Government of India Open Data API to retrieve agricultural market price information.

▶️ How to Run

1. Clone the repository.
2. Open the project in Eclipse or any Java IDE.
3. Configure MySQL database.
4. Configure the required API key.
5. Run the Spring Boot application.
6. Test the APIs using Postman or the application interface.
